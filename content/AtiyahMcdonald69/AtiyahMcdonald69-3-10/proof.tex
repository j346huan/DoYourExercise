\textbf{(i)} By \exref{2.27}, absolute flatness is equivalent to every principal ideal being idempotent. If $x=x^2a$ in $A$, then $x/s=as(x/s)^2$ in $S^{-1}A$, so the same criterion applies.

\textbf{(ii)} Suppose $A$ is absolutely flat. By (i), so is $A_{\mathfrak m}$. For $x\in A_{\mathfrak m}$, write $x=x^2a$. If $x$ is not a unit, then $1-ax$ is a unit because $A_{\mathfrak m}$ is local. Thus $x(1-ax)=0$ implies $x=0$. Hence $A_{\mathfrak m}$ is a field.

Conversely, if every $A_{\mathfrak m}$ is a field, then for every $A$-module $M$, each $M_{\mathfrak m}$ is flat over $A_{\mathfrak m}$. The local criterion for flatness shows that every $M$ is flat.
