Define $\alpha(\mu_i(x))=\alpha_i(x)$. If $\mu_i(x)=\mu_j(y)$, choose $k\geq i,j$. By \exref{2.15}, the element $\mu_{ik}(x)-\mu_{jk}(y)$ becomes zero in some $M_l$ with $l\geq k$. Compatibility then gives $\alpha_i(x)=\alpha_j(y)$, so $\alpha$ is well-defined. Moving finitely many representatives to a common stage shows that it is $A$-linear. It is unique because every element has the form $\mu_i(x)$.

If another module with structure maps has this property, the two universal properties give maps between it and $M$. Their composites fix all structure maps, so uniqueness makes both composites identities.
