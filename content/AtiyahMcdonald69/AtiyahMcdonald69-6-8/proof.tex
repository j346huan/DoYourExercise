Every open subset of $\operatorname{Spec}(A)$ has the form $\operatorname{Spec}(A)\setminus V(\mathfrak a)$. If $A$ is Noetherian, write $\mathfrak a=(a_1,\ldots,a_n)$. This open set is $\bigcup_iD(a_i)$, a finite union of quasi-compact spaces, so it is quasi-compact. Apply \exref{6.6}.

The converse fails for $A=k[x_1,x_2,\ldots]/(x_i^2:i\ge1)$. Every prime contains every $x_i$, so the spectrum consists of the single point $(x_1,x_2,\ldots)$. However, $(x_1)\subsetneq(x_1,x_2)\subsetneq\cdots$ is a strictly ascending chain of ideals, so $A$ is not Noetherian.
