Multiplication by $ab$ is injective exactly when multiplication by both $a$ and $b$ is injective, so $S_0$ is saturated. Let $\mathfrak p$ be a minimal prime. By \exref{3.6}, $A\setminus\mathfrak p$ is maximal among multiplicatively closed sets excluding $0$. It contains every non-zero-divisor $t$, since adjoining the powers of $t$ cannot introduce $0$. Hence $\mathfrak p$ consists of zero-divisors.

\textbf{(i)} If $a/1=0$ in $S_0^{-1}A$, then $sa=0$ for a non-zero-divisor $s$, so $a=0$. If a multiplicatively closed set contains a zero-divisor $s$, choose $a\ne0$ with $sa=0$. Then $a$ maps to zero, so the localization map is not injective.

\textbf{(ii)} If $a\in S_0$, then $a/s$ has inverse $s/a$. Otherwise, choose $b\ne0$ with $ba=0$. By (i), $b/1\ne0$, and $(b/1)(a/s)=0$.

\textbf{(iii)} Under this assumption $S_0=A^\times$, and $a/s\mapsto as^{-1}$ is inverse to the localization map.
