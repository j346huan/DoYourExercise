The complement of $V(\mathfrak a)$ is $\bigcup_{f\in\mathfrak a}D(f)$, so the $D(f)$ form a basis. Primality gives $D(f)\cap D(g)=D(fg)$. Also $D(f)=\varnothing$ iff $f$ belongs to every prime, iff it is nilpotent; and $D(f)=\operatorname{Spec}A$ iff $f$ belongs to no maximal ideal, iff it is a unit. Finally, $D(f)=D(g)$ iff $V(f)=V(g)$, which is equivalent to $\sqrt{(f)}=\sqrt{(g)}$ by intersection of primes.

If the $D(f_i)$ cover $\operatorname{Spec}A$, then the $f_i$ generate the unit ideal. Write $1=\sum_{i\in J}a_if_i$ for a finite set $J$. No prime contains all these $f_i$, so the corresponding finite family covers the spectrum.

More generally, if $D(f)\subseteq\bigcup_iD(f_i)$, then every prime containing the $f_i$ contains $f$. Thus $f^n\in(f_i:i\in I)$ for some $n$, and this relation uses only finitely many $f_i$. Those basic opens cover $D(f)$. Arbitrary open covers can be refined by basic opens, proving quasi-compactness. A quasi-compact open is a finite union of basic opens; conversely, a finite union of quasi-compact sets is quasi-compact.
