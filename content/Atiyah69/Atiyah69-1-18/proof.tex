\textbf{(i)} By (ii), $\{x\}$ is closed iff $x$ is the only prime ideal containing itself, iff it is maximal.

\textbf{(ii)} If $x\in V(\mathfrak a)$, then $\mathfrak a\subseteq x$, so the smallest closed set containg $x$ corresponds to the largest ideal inside $x$ which is $x$ itself, so closure is $V(x)$.

\textbf{(iii)} $y\in\overline{\{x\}}$ iff $y\in V(x)$ iff $x\subseteq y$.

\textbf{(iv)} If $x,y$ are two distinct points, then either $x\nsubseteq y$ or $y\nsubseteq x$, so by (iii) either $x\notin\overline{\{y\}}$ or $y\notin\overline{\{x\}}$, so either there is a neighbourhood around $x$ not containing $y$ (take $X-\overline{\{y\}}$), or the other way around.
