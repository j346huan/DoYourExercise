A closed set $V(\mathfrak a)$ contains $x$ iff $\mathfrak a\subseteq\mathfrak p_x$. The smallest such closed set is $V(\mathfrak p_x)$, so $\overline{\{x\}}=V(\mathfrak p_x)$ and $y\in\overline{\{x\}}$ iff $\mathfrak p_x\subseteq\mathfrak p_y$. Hence $x$ is closed iff $\mathfrak p_x$ is maximal.

If $x\ne y$, choose an element belonging to one of their prime ideals but not the other. Its basic open contains exactly one of the two points, proving the $T_0$ property.
