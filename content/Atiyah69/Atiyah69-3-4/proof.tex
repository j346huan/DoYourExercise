Define $S^{-1}B\to T^{-1}B$ by $b/s\mapsto b/f(s)$. If $b/s=c/t$, some $u\in S$ satisfies $f(u)(f(t)b-f(s)c)=0$, which is precisely the equality criterion in $T^{-1}B$. Thus the map is well defined and is clearly $S^{-1}A$-linear and surjective. If $b/f(s)=0$, some $t\in S$ satisfies $f(t)b=0$, so $b/s=0$ in $S^{-1}B$. Hence the map is an isomorphism.
