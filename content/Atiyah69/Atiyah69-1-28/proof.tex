We need an inverse to the above identification. Suppose we have a $k$-algebra homomorphism $\varphi:A(Y)\to A(X)$. Let $f_i=\varphi(y_i)\in A(X)$. Now define $f:X\to Y$ by $f(x)=(f_1(x),\ldots,f_m(x))$ is regular. $g\circ f$ is equal to $\varphi(g)$ because
\[
g(f(x))=g(f_1(x),\ldots,f_m(x))=g(\varphi(y_1)(x),\ldots,\varphi(y_m)(x))=\varphi(g)(x)
\]
(since $\varphi$ is algebra homomorphism). The image lies inside $Y$ because $g\circ f=\varphi(g)=0$ for all $g\in I(Y)$, so $f(x)\in V(I(Y))=Y$.
