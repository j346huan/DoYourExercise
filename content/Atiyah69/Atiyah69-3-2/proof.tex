If $b\in\mathfrak a$, $c\in A$ and $s,t\in S$, then $1-(b/s)(c/t)=(st-bc)/(st)$ is a unit, since $st-bc\in1+\mathfrak a$. Hence $S^{-1}\mathfrak a$ is contained in the Jacobson radical.

Now $S^{-1}M=(S^{-1}\mathfrak a)(S^{-1}M)$, so Nakayama's lemma gives $S^{-1}M=0$. The required form of Nakayama follows directly from a minimal generating set: if a nonzero finitely generated module $N$ satisfies $N=IN$, with $I$ in the Jacobson radical, a minimal set $x_1,\ldots,x_n$ satisfies $x_n=\sum_i a_ix_i$ for $a_i\in I$. Since $1-a_n$ is a unit, $x_n$ is redundant, a contradiction. By \exref{3.1}, some $1+a\in S$ annihilates $M$.
