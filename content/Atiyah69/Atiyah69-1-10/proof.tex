\textbf{(i) $\Rightarrow$ (ii)} Only one prime ideal means only one maximal ideal, and it is exactly the nilradical. So the ring is local and elements are either units or nilpotent.

\textbf{(ii) $\Rightarrow$ (iii)} We have all the non-units form an ideal, the nilradical. So the ring is local and it is maximal. Hence quotient is field.

\textbf{(iii) $\Rightarrow$ (i)} If it has more than one prime ideals, then the nilradical must not be maximal, so the quotient is not a field.
