The canonical map $A\to U^{-1}(S^{-1}A)$ sends every element of $ST$ to a unit, so it induces $a/(st)\mapsto(a/s)/(t/1)$. This map is surjective. If the image of $a/(st)$ is zero, some $t'\in T$ satisfies $t'a/1=0$ in $S^{-1}A$, and then $s't'a=0$ for some $s'\in S$. Thus $a/(st)=0$ in $(ST)^{-1}A$, proving injectivity.
