\textbf{(i)} Since $f(1-f)=0$, a prime contains exactly one of $f$ and $1-f$, so $D(f)\cup D(1-f)=X$ and they are both closed and open.

\textbf{(ii)} $\mathfrak p$ does not contain $1-(1-f)(1-g)$ iff it contains $(1-f)(1-g)$, which means it either does not contain $g$ or $f$. So
\[
D(f)\cup D(g)=D(1-(1-f)(1-g))=D(1-1+f+g-fg)=D(fg-f-g).
\]
Since $1=(-1)^2=-1$, this is the same as $D(f+g+fg)$.

\textbf{(iii)} See hint.

\textbf{(iv)} Hausdorff because $D(f)$ form a basis. Compact because quasi-compact.
