For each $\mathfrak p\in\operatorname{Spec}(A)$, tensor products commute with directed limits, giving $B\otimes_A k(\mathfrak p)\cong\varinjlim_\alpha(B_\alpha\otimes_A k(\mathfrak p))$. A directed limit of rings is zero exactly when some ring in the system is zero: if $1=0$ in the limit, this equality already holds at some stage. Hence $B\otimes_A k(\mathfrak p)\ne0$ exactly when every $B_\alpha\otimes_A k(\mathfrak p)\ne0$. Apply the fiber description in \exref{3.21}.
