\textbf{(i)} If $x^n\in\mathfrak a\subseteq\mathfrak p$ then $x\in\mathfrak p$ so $\sqrt{\mathfrak a}\subseteq\mathfrak p$. Hence $V(E)=V(\mathfrak a)=V(\sqrt{\mathfrak a})$.

\textbf{(ii)} All primes contain $0$, no prime contain $1$.

\textbf{(iii)} A prime contains all $E_i$ iff it contains each $E_i$.

\textbf{(iv)} $V(\mathfrak a\cap\mathfrak b)=V(\sqrt{\mathfrak a\cap\mathfrak b})=V(\sqrt{\mathfrak a\mathfrak b})=V(\mathfrak a\mathfrak b)$ by 1.13(iii). A prime contains $\mathfrak a\mathfrak b$ implies it either contains $\mathfrak a$ or some $a\in\mathfrak a$ is not in $\mathfrak p$, then $a\mathfrak b\subseteq\mathfrak p$ implies $\mathfrak p$ contains $\mathfrak b$, so $V(\mathfrak a\mathfrak b)=V(\mathfrak a)\cup V(\mathfrak b)$.
