\textbf{(i)} Expanding $(x+1)^2=x+1$ and using $x^2=x$ gives $2x=0$.

\textbf{(ii)} Every element of the domain $A/\mathfrak p$ satisfies $x(x-1)=0$, so it equals $0$ or $1$. Thus $A/\mathfrak p\cong\mathbb F_2$ and $\mathfrak p$ is maximal.

\textbf{(iii)} Put $c=a+b+ab$. Then $c\in(a,b)$, while $ac=a$ and $bc=b$, so $(a,b)=(c)$. Induction gives the result for any finite set of generators.
