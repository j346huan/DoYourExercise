A morphism $\operatorname{Spec}K\to X$ determines its image $x$ and a local homomorphism $\mathcal O_{X,x}\to K$. Its kernel is $\mathfrak m_x$, so it induces an inclusion $k(x)\to K$. Conversely, such an inclusion determines the local homomorphism $\mathcal O_{X,x}\to k(x)\to K$. On an open set containing $x$, compose this with the germ map from its sections; on every other open set use the unique map to $0$. These maps define a morphism, and the constructions are inverse.
