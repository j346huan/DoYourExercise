(a) A common zero of $T_2$ is a common zero of $T_1$.

(b) A homogeneous polynomial vanishing on $Y_2$ vanishes on $Y_1$.

(c) A homogeneous polynomial vanishes on $Y_1\cup Y_2$ exactly when it vanishes on both sets, so $I(Y_1\cup Y_2)=I(Y_1)\cap I(Y_2)$.

(d) The inclusion $\sqrt{\mathfrak a}\subseteq I(Z(\mathfrak a))$ is immediate. The reverse inclusion in positive degrees follows from \exref{I.2.1}; in degree zero it follows because $Z(\mathfrak a)\ne\varnothing$.

(e) $Z(I(Y))$ is closed and contains $Y$. Every closed set containing $Y$ is defined by homogeneous polynomials in $I(Y)$, so it contains $Z(I(Y))$. Hence $Z(I(Y))=\overline Y$.
